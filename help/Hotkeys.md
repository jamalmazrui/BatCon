# BatCon Hotkeys

## Anywhere in Windows

- **Alt+Control+B:** open BatCon.

## In the dialog

- **Alt+A:** Add folder.
- **Alt+B:** Browse source.
- **Alt+C:** Choose output.
- **Alt+F:** Force replacements.
- **Alt+I:** Include subfolders.
- **Alt+O:** Output directory.
- **Alt+S:** Source files.
- **Alt+T:** Target format.
- **Alt+V:** View output.
- **Enter:** OK, which starts the batch.
- **Escape:** Cancel.
- **Control+Enter:** OK, from anywhere in the dialog.
- **Shift+F1:** the tip for the field with the focus.
