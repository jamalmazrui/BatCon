# BatCon Hotkeys

## Anywhere in Windows

- **Alt+Control+B:** open BatCon.

## In the dialog

- **Alt+B:** Browse source.
- **Alt+C:** Choose output.
- **Alt+F:** Force replacements.
- **Alt+I:** Include subfolders.
- **Alt+L:** Log session.
- **Alt+O:** Output directory.
- **Alt+S:** Source files.
- **Alt+T:** Target format.
- **Alt+U:** Use configuration.
- **Alt+V:** View output.
- **Control+Enter:** OK, from anywhere in the dialog.
- **Enter:** OK, which starts the batch.
- **Escape:** Cancel.
- **F1:** Help, which lists each field and checks for a newer BatCon.
- **F11:** check for a newer BatCon at once.
- **Shift+F1:** the tip for the field with the focus.
