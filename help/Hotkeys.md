# BatCon Hotkeys

## Anywhere in Windows

- **Alt+Control+B:** open BatCon.

## In the dialog

- **Alt+B:** Browse local source.
- **Alt+C:** Choose output directory.
- **Alt+D:** Default settings.
- **Alt+F:** Force replacements.
- **Alt+H:** Help.
- **Alt+O:** Output directory.
- **Alt+S:** Source paths.
- **Alt+T:** Target format.
- **Alt+U:** Use configuration.
- **Alt+V:** View output directory.
- **Control+Enter:** OK, from anywhere in the dialog.
- **Enter:** OK, which starts the batch, except on a button, which Enter presses.
- **Escape:** Cancel, from anywhere in the dialog.
- **F1:** Help, which lists each field, says where the logs are, and checks for a newer BatCon.
- **F11:** check for a newer BatCon at once, from anywhere in the dialog.
- **Shift+F1:** the tip for the field with the focus.
