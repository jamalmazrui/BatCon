# BatCon Announcement

BatCon is a new free tool for Windows that converts many files at once: PDF to Markdown, Word to a web page, Markdown to Word or PowerPoint, a table to Excel, and more. You name the files, folders or patterns, pick a format from a list of the ones they all convert to, and choose where the results go. It works with JAWS, NVDA and the keyboard, and it uses the same conversions as the other Homer Tools.

Learn more and download it at the BatCon page on GitHub.
