# BatCon

BatCon converts many files at once from one format to another: PDF to Markdown, Word to web page, Markdown to Word or PowerPoint, an inix table to Excel, and more. It uses the same conversions as the other Homer Tools, so a file converts the same way in BatCon as in FileDir or EdSharp. It is free and open source under the [MIT License](License.htm).

## Quick start

1. Press Alt+Control+B to open BatCon.
2. In Source files, type a file, a folder or a pattern such as `*.pdf`, or press Alt+B to browse.
3. In Target format, pick what to convert to. The list shows only the formats every source converts to.
4. In Output directory, choose where the results go, or leave it blank to write each beside its source.
5. Press Enter. BatCon tells you how far it has got, then shows what it converted, skipped or failed.

The full guide is [BatCon](help/BatCon.htm), and every key is in [Hotkeys](help/Hotkeys.htm).
